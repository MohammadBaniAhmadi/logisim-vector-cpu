# Architecture and instruction notes

This page summarizes information documented in the original Persian-language course [report](../Report.pdf), supplemented by inspection of the Logisim-evolution circuit structure. It is a **design summary, not a claim of formal verification**.

## Register organization

- **31 vector registers**, each **128 bits** wide.
- Each 128-bit register is realized as **two 64-bit halves**, because the report describes limitations of the available register primitive.
- The vector read and write interfaces are adapted to handle the pair of 64-bit components.

## Vector ALU

The vector ALU executes a common operation across independent lanes:

| Datapath | Parallel lanes | Per-lane operation | Vector result width |
| --- | ---: | ---: | ---: |
| `VectorALU32` | 4 | 32 bits | 128 bits |
| `VectorALU16` | 8 | 16 bits | 128 bits |

The report describes extending 16-bit lane inputs to 32 bits for processing and then assembling the 16 least significant bits of each result into the output vector.

## Vector instructions

The report specifies a vector instruction opcode of `100000`, with the following **6-bit function fields**:

| Instruction | Function code |
| --- | --- |
| `MUL32V` | `000011` |
| `ADD32V` | `000101` |
| `SUB32V` | `001001` |
| `MUL16V` | `010001` |
| `ADD16V` | `000110` |
| `SUB16V` | `001010` |
| `VAND` | `010010` |
| `VOR` | `001100` |
| `VXOR` | `010100` |
| `VNOT` | `011000` |

The report also documents scalar/vector register transfer operations:

| Instruction | Opcode |
| --- | --- |
| `TOCOP` | `111111` |
| `FROMCOP` | `011111` |

These encodings are transcribed from the report rather than generated by an automated test.

## Notable subcircuits

The supplied `.circ` file contains named subcircuits including `main`, `ALU`, `OALU`, `VectorALU16`, `VectorALU32`, `RegisterFile`, `regfile`, `VSelector`, and `selectFunc`.

## Implementation limits

The report states that the optional extra-credit portion was not implemented and that the memory portion was not modified for that optional extension. The schematic builds on a previously implemented CPU design.
